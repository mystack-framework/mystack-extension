# Changelog

All notable extension-package changes are documented here. Package versions describe VS Code extension delivery only; MyStack Framework itself follows a versionless rolling `main` branch.

## 1.1.0

- Rebuilt IDE stubs from current MyStack source and fixed invalid PHP declarations.
- Expanded metadata to all 98 discovered framework symbols and 2,400+ snippets.
- Added PHFY, PHMO and complete current-library syntax coverage.
- Added safe multi-root initialization, atomic workspace writes and workspace-trust enforcement.
- Corrected Intelephense configuration to use a directory include path.
- Added documentation, Doctor, Smoke, refresh and command-picker actions.
- Registered the MyStack TextMate grammar correctly.
- Added deterministic validation and source-sync maintainer tooling.
- Updated official ownership, repository, security, contribution and packaging metadata.

## 1.0.0

- Initial helper release with PHP snippets, basic workspace initialization and bundled stubs.
